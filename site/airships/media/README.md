# media

Stills of the vehicle, rendered from the model in `3d/` — not artwork, and not
photographs of anything. Each is a screenshot of the same WebGL model the pages run,
posed and cropped.

| file | what it shows |
|---|---|
| `vacuum.jpg` | the cell structure that produces lift, in cutaway |
| `intake.jpg` | the hose and pump pod, during a fill |
| `drop.jpg` | a drop run, water leaving the sprayers |
| `ballast.jpg` | the ballast and cryogenic plant |

Regenerate: `make figures` (see `tools/README.md`). They are committed because the
pages need them offline and because a render of a model is data about that model —
if the model changes and these do not, the pages are showing an old vehicle.
