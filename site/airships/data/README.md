are in [DATA-SOURCES.md](../DATA-SOURCES.md) and [NOTICE](../NOTICE).

## Count correction

The earlier README said six files; it omitted the historical-fire dataset. It also described the
pre-regeneration Natural Earth vectors: 294 road polylines / 3,032 vertices and 23 outline rings /
804 vertices. Those historical values are retained here as the old values, not current measurements.
The table above is measured from the current files. `pipeline/vectors.py` now reproduces the vectors
from the pinned Natural Earth archive recorded in their sidecars. The notice repair changes no geometry.

Snapshot files are pinned test inputs. Re-fetching them changes the replay. This notice generator only
reads local bytes; it never calls an agency feed. Surface area is a proxy for water access, and simplified
historical perimeters are not operational fire lines. Providers do not endorse this project.
